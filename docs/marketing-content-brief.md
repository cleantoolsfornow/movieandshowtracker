# FilmPickle Marketing Content Brief

## Purpose

This document captures the current marketing and public-site decisions for FilmPickle so page writing stays consistent, accurate, and on-brand.

It is intentionally practical and should be used as the source of truth when drafting or updating:

- homepage copy
- features copy
- FAQ
- support page
- how-it-works page
- public CTA language

## Brand

- Product name: `FilmPickle`
- Domain: `filmpickle.com`
- Brand direction: playful, cool, cutesy, and cheeky
- Tone constraint: should not feel like it is trying too hard

## Positioning

FilmPickle should be positioned as a product for:

- solo users
- couples
- roommates
- households

Core positioning rule:

- the product should clearly feel like it works for anyone
- solo users should not feel like they are using an awkward "household of one"
- shared use should feel like a natural expansion path, not the only real mode

Preferred framing:

- `personal tracker` for solo usage
- `shared household` for multi-user usage

Avoid overusing:

- `solo household`

That concept can still exist in product architecture, but public-facing copy should generally say:

- `personal tracker`
- `solo mode`
- `use it by yourself`

## Current product truth

Public marketing should reflect what the app actually does now.

Current capabilities that are safe to market as live:

- users can sign up and sign in
- users can create a household
- users can join a household by invite code
- users can use the app by themselves
- users can invite others later
- users can search for movies and TV shows
- users can save titles quickly
- users can track personal status on a title
- users can mark titles as:
  - want to watch
  - watched
- users can add:
  - personal rating
  - personal notes
- households can track:
  - shared watchlist state
  - watched together events
- watched together can include participants for larger households
- the library is visual and poster-first
- the dashboard and title views adapt based on solo / two-person / 3+ household usage

## Planned / future-facing features

These should not be marketed as fully live yet.

They can be referenced as planned or future improvements when needed:

- TV episode progress
- TV season progress
- richer continue-watching behavior
- account deletion
- leaving a household
- import / export
- more advanced decision support
- richer shortlist / pick-tonight flows

## Messaging guardrails

The site should sell the product strongly, but not oversell features that are not fully there yet.

### Safe message themes

- save titles quickly before you forget them
- keep your watchlist cleaner and easier to browse
- track what you want to watch and what you have watched
- use it by yourself or with people you watch with
- make shared watch decisions easier

### Be careful with these claims

These can be implied as goals, but should not be described like mature, deeply developed systems unless the page clearly marks them as planned:

- shortlist engine
- clear front-runner logic
- household momentum intelligence
- advanced watch-night picker
- TV episode progress
- rewatch history depth

### Best framing

Prefer:

- `helps make picking something easier`
- `keeps shared context visible`
- `gives you a cleaner way to track together`

Over:

- `automatically tells you exactly what to watch tonight`
- `fully manages show progress`
- `intelligently ranks your household queue`

## Audience framing

The public site should speak to all of these:

- solo users
- couples
- spouses
- boyfriends / girlfriends
- roommates
- households with 3+ members

That should appear naturally across pages so users can quickly self-identify.

Examples:

- `Use FilmPickle by yourself, with your partner, with roommates, or across a full household.`
- `Great for personal queues, couples, and shared household watchlists.`

## Platform framing

The app should be pitched as usable anywhere.

Public framing should support:

- web app
- mobile web usage

Preferred language:

- `Works great on the web and is especially handy on mobile.`
- `Easy to use wherever you keep up with what to watch next.`

Avoid making native-app claims.

## Pricing / support framing

- Current pricing: free
- Current monetization/support model: donations only

Public language should say:

- the app is free right now
- support is optional
- donations help keep the project moving

## FAQ requirements

The FAQ should include honest answers for:

- Can I use FilmPickle by myself?
- Do I need to create a household?
- Can I invite someone later?
- Is FilmPickle free?
- Does it work for couples?
- Does it work for roommates or larger households?
- Does FilmPickle support TV season or episode progress?
  Answer: not yet, planned for the future
- Can I leave a household?
  Answer: not currently, planned for the future
- Can I delete my account?
  Answer: not currently, planned for the future
- Can I import or export my data?
  Answer: not currently
- Can I use it on my phone?
  Answer: yes, it is intended to work well on the web, including mobile web

## How-it-works page requirements

The page should explain both flows clearly.

### Personal tracker flow

- create account
- create your personal tracker
- search and save titles
- mark what you want to watch
- mark what you have watched
- later, invite others if you want

### Shared household flow

- create account
- create a household or join one by invite code
- add titles for yourself and the household
- track personal and shared watch states
- keep everyone more aligned on what has been watched and what still sounds good

Important messaging point:

- users can create a household whenever they want
- shared use is not required at the beginning

## Style guidance for page writing

The writing should be:

- playful
- warm
- lightly cheeky
- easy to understand
- clear about what exists today

The writing should not be:

- stiff
- overhyped
- too startup-generic
- too cute to the point of losing clarity

## Example voice cues

Good:

- `Save the movie someone just recommended before it disappears into the void.`
- `Keep your personal picks and your shared picks from turning into one big mess.`
- `Use it by yourself now, invite people later if your watch life gets more collaborative.`

Bad:

- overly quirky copy on every line
- copy that sounds like a joke before it sounds useful
- copy that claims deep recommendation or ranking systems that do not exist yet

## Working message hierarchy

### Primary message

FilmPickle is a playful movie and show tracker you can use by yourself or with the people you watch with.

### Secondary message

It helps you save titles fast, keep your queue cleaner, and make shared watch decisions easier.

### Supporting message

Start with a personal tracker, then grow into couples, roommate, or household use whenever you want.
